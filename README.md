# ICK-Opportunities

Build the initial foundation for a production-quality web application called ICK Opportunities.



ICK Opportunities is a Nigeria-first opportunity discovery platform that helps users discover relevant scholarships, jobs, internships, and grants.



For this first step, DO NOT build the full application yet.



Create only a clean, modern, responsive foundation with:



1. A professional landing page for ICK Opportunities.

2. A top navigation bar with:

   - Home

   - Opportunities

   - Scholarships

   - Jobs

   - Internships

   - Grants

   - Sign In

   - Get Started

3. A hero section with:

   - Headline: "Find Opportunities. Build Your Future."

   - Supporting text explaining that users can discover scholarships, jobs, internships and grants relevant to their goals.

   - Primary CTA: "Find Opportunities"

   - Secondary CTA: "Build My CV"

4. A simple search section for opportunities.

5. A featured opportunities section using realistic placeholder data only.

6. A short trust/verification section explaining that opportunities will be checked against official sources.

7. A simple footer.



Design direction:



- Modern

- Trustworthy

- Youthful

- Professional

- Nigeria-first

- Premium but not flashy

- Mobile-first and fully responsive

- Use deep navy/midnight blue as the primary visual direction, modern blue as a secondary accent, and green sparingly for verification/success states.

- Use a clean sans-serif typeface such as Inter or Plus Jakarta Sans.

- Avoid a government-portal appearance.

- Avoid excessive gradients, animations, glassmorphism, or unnecessary decorative elements.



Important technical constraints:



- Use clean, maintainable component structure.

- Do not create fake authentication.

- Do not create a database yet.

- Do not connect Supabase yet.

- Do not add AI functionality yet.

- Do not add payment functionality.

- Do not implement automatic application submission.

- Use placeholder opportunity data only.

- Do not expose secrets or API keys.

- Keep the architecture easy to extend in later steps.



Before finishing, make sure the page works correctly on both mobile and desktop and that navigation and buttons have sensible placeholder destinations or clearly defined temporary behavior.



Do not proceed beyond this foundation.
